# Tugas Praktikum Naive Bayes dan Logistic Regression

Terdapat dua tugas pada modul ini. Masing-masing dikerjakan pada notebook yang berbeda.

## Tugas 1 - Mushroom Classification

**Dataset:** https://www.kaggle.com/datasets/uciml/mushroom-classification

**File notebook:** `1_NB_Logreg_NRP.ipynb`

Dataset ini berisi karakteristik fisik jamur dari 23 spesies. Semua fitur bertipe kategorikal dan direpresentasikan sebagai kode huruf singkat. Tujuannya adalah mengklasifikasikan apakah suatu jamur dapat dimakan (edible) atau beracun (poisonous).

Pada tugas ini kalian akan membangun dan membandingkan tiga varian Naive Bayes:
- Categorical Naive Bayes
- Bernoulli Naive Bayes
- Multinomial Naive Bayes

Karena setiap varian membutuhkan representasi data yang berbeda, preprocessing untuk masing-masing model tidak sama. Baca baik-baik keterangan di setiap section sebelum menulis kode.


## Tugas 2 - Pima Indians Diabetes

**Dataset:** https://www.kaggle.com/datasets/jamaltariqcheema/pima-indians-diabetes-dataset

**File notebook:** `2_NB_Logreg_NRP.ipynb`

Dataset ini berisi data medis pasien perempuan keturunan Pima Indian. Tujuannya adalah memprediksi apakah seorang pasien menderita diabetes atau tidak berdasarkan 8 fitur numerik seperti kadar glukosa, BMI, dan tekanan darah.

Pada tugas ini kalian akan membangun dan membandingkan dua model:
- Gaussian Naive Bayes
- Logistic Regression
