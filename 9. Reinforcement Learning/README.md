# Tugas Praktikum Reinforcement Learning

**Project:** bebas (tentukan sendiri masalah, environment, dan algoritma RL-nya)

### Deskripsi

Praktikum ini memperkenalkan konsep dasar Reinforcement Learning (RL) melalui interaksi antara agent dan environment. Berbeda dengan supervised learning, data tidak diberikan dalam bentuk label. Agent belajar sendiri dengan mencoba action, menerima reward, lalu memperbaiki strateginya.

Konsep utama yang dipraktikkan:

- Agent
- Environment
- State
- Action
- Reward
- Policy
- Value
- Proses pembelajaran melalui interaksi
- Evaluasi strategi agent

Project dan algoritma dibebaskan. Pastikan konsep-konsep di atas muncul di project kalian dan bisa dijelaskan dengan hasil eksperimen sendiri.

## Ketentuan Pengerjaan

- Kerjakan secara mandiri.
- Isi bagian analisis dan kesimpulan berdasarkan hasil eksperimen kalian sendiri, bukan hasil orang lain.
- Program harus bisa dijalankan ulang dari awal sampai akhir.
- Cantumkan sumber bila memakai kode atau ide dari luar.
